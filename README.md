# 自由帳

ローカルサーバー上で起動する簡易お絵かきツール。
stdioのMCPを備えていて、適当に描いた図面をAIに共有できる。
(ということのために作った)

## お絵描きツールとしての特徴

- レイヤーが線と筆しかない（線が上）
- 適当に書いたらどんどん記録されていく
- 名前つけられてそれで調べられる（さっき書いた○○設計図見て、とかAIに言える）
- キャンバスサイズがない（どこまでも延長できる）

## 使い方

```sh
go build -o jiyucho.exe .
./jiyucho.exe
```

フロントエンド(`frontend/`、Vite + Vue SFC)のビルド結果は `web/` に出力されて Go に埋め込まれます。
`web/` はコミット済みなので、フロントを触らなければ Node.js なしで `go build` できます。

```sh
cd frontend
npm install
npm run build   # → ../web に出力
```

開発時は API 用にアプリを起動しておき、Vite の開発サーバーから使います。

```sh
./jiyucho.exe -port 8787 -no-open
cd frontend && npm run dev   # http://localhost:5173 (/api は 8787 へ中継)
```

| オプション    | 説明                                                  |
| ------------- | ----------------------------------------------------- |
| `-data <dir>` | データの保存先を変更します(既定: `%AppData%\jiyucho`) |
| `-port <n>`   | 待ち受けポート(既定: 0 = 自動)                        |
| `-no-open`    | ブラウザを自動で開きません                            |

### 操作

| 操作                | 方法                                                           |
| ------------------- | -------------------------------------------------------------- |
| 拡大縮小            | マウスホイール                                                 |
| 移動                | スペース + ドラッグ、中ボタン + ドラッグ、または「移動」ツール |
| 元に戻す / やり直し | `Ctrl+Z` / `Ctrl+Y`(`Ctrl+Shift+Z`)                            |

## MCP (stdio)

AI クライアントから絵を参照できます。

```json
{
  "mcpServers": {
    "jiyucho": { "command": "/path/to/jiyucho.exe", "args": ["mcp"] }
  }
}
```

提供するツール:

| ツール                        | 内容                                                                                                       |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `list_images(query?, limit?)` | 保存済みの絵を新しい順に一覧。`query` を指定するとタイトルまたは ID で絞り込み(大文字小文字は区別しません) |
| `get_image(id, background?)`  | ID を指定して画像を取得。背景の指定がなければ、その絵の紙の色を使います                                    |
